Commands:

Finding: Found login page at /login and upload form at /admin

## Task 2 - Web Exploitation
Q: How to bypass login?
A: SQL Injection / Brute Force

Payload used:
' OR 1=1 -- -
admin' --

Method:
1. Cek source code (CTRL+U)
2. Coba SQLi di parameter username
3. Login berhasil sebagai admin

Q: How to get reverse shell?
A: Via File Upload bypass

Method:
1. Upload shell.php dengan extension .phtml
2. Intercept dengan BurpSuite -> change MIME type
3. Access /uploads/shell.phtml
4. nc -lvnp 4444
5. Got shell as www-data

## Commands Used

BurpSuite for interception
nc -lvnp 4444 - reverse shell
cat /etc/passwd, ls -la

## Exploit Chain Summary
1. Nmap -> port 80 open
2. Gobuster -> /admin /login
3. Source code review -> hint SQLi
4. SQLi -> Admin login bypass
5. File Upload -> RCE -> Reverse Shell
6. Priv Esc check -> user.txt

## Note / Learning
- Selalu cek source code web, banyak clue di comment HTML
- File upload filter bisa di bypass pake .phtml, .php5, %00
- SQLi paling basic ' OR 1=1 -- - masih work di lab THM
- BurpSuite itu kunci buat web hacking
- Jangan lupa gobuster dengan wordlist medium, bukan common doang

## Mitigation
- Use prepared statements for SQL
- Whitelist file upload extension
- Hide error messages, disable directory listing
